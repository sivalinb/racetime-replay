# Visual assets

The public repository uses code-authored diagrams of video and workout ingestion, alignment, and evidence review. They contain no personal photographs and make no measured performance claims.

- `assets/architecture/replay-readme-intro.svg` explains Capture → Align → Review.
- `assets/architecture/replay-readme-architecture.svg` maps the local pipeline and optional cloud boundaries.
- PNG versions provide previews in the README and illustrated product guide.
- `scripts/build_readme_diagrams.py` regenerates the editable SVG sources.
- `assets/replay-workflow.svg` provides the compact workflow view.

The personalized running illustration and illustrated overview remain separate local deliverables. They are excluded from the public source tree and are not licensed as a training dataset.
